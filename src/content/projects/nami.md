Nami is a unified AI chat app: one place to talk to the major LLMs instead of a separate app for each.

It is also the project that _Advanced Android: From Code to Production_ is built around. Instead of isolated examples, every topic in the course is applied to the Nami codebase, so the result is a real app that can be shipped.

## What the course covers

- Architecture and design patterns
- Kotlin in depth
- Jetpack Compose and accessibility
- Networking, data and persistence
- Performance, optimization and background work
- Security and testing
- Publishing, DevOps and monetization

The course repository is public on [GitHub](https://github.com/karacca/nami-android).
